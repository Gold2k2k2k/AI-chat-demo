## 1. 项目简介与产品定位
**项目简介**：
本项目是一个基于纯前端原生技术（HTML/CSS/JS）构建的智能 AI 聊天对话交互界面。

**产品定位**：
作为连接用户与大语言模型（如 DeepSeek）的 Web 客户端界面演示。它致力于提供极简、美观、流畅的用户体验，内置了侧边栏模型状态展示、快捷指令卡片、气泡对话流体排版、输入区自适应高度、以及纯前端实现的 Markdown 文本渲染与代码高亮等核心功能。此版本为**纯前端演示模式**，主要用于展示产品设计、还原使用流程与前端交互体验。

## 2. 启动方式与环境变量说明
**启动方式**：
本项目为纯静态前端单文件项目，坚持“开箱即用”，无需安装 Node.js、NPM 依赖或任何打包构建工具。
1. 下载或克隆本项目代码。
2. 直接在任意现代浏览器（Chrome, Edge, Firefox, Safari 等）中双击打开 `index.html` 文件，即可运行并体验全部交互功能。

**环境变量说明**：
由于当前是纯前端 Demo 演示模式，**无需配置任何环境变量**。
*(扩展补充：若后续需改造接入真实的后端大模型服务，需在后端或环境变量管理中配置 `DEEPSEEK_API_KEY`，并配置网关地址（如代码中提及的 `tokendance.space`）以完成对 `deepseek-y4-flash-0731` 模型的真实 API 鉴权与调用。)*

## 3. 核心使用流程与 AI 介入环节说明
**核心使用流程**：
1. **进入应用**：打开页面后，界面展示带有动态欢迎语的初始状态，以及四个核心场景快捷提问卡片（写代码、解释概念、翻译、创作）。
2. **输入与提问**：用户可点击任意快捷卡片（一键填入预设 Prompt 并触发 Toast 提示），或在底部的多行输入框中手动输入问题。
3. **发送指令**：按下 `Enter` 键（支持 `Shift+Enter` 换行）或点击“发送”按钮，消息以右侧气泡形式上屏，输入框自动清空并还原高度。
4. **等待响应**：界面左侧出现 AI 专属的“打字机”加载动画（Typing Indicator），在此期间发送按钮置灰，防止重复提交。
5. **获取结果**：加载结束后获得 AI 回复，系统自动将 Markdown 格式文本渲染为易于阅读的 HTML 结构，包含代码块（深色主题）、列表、加粗、引用等样式。
6. **重置对话**：点击输入框左侧的“🗑”垃圾桶图标，即可一键清空当前所有上下文对话记录，界面恢复至初始欢迎状态。

**AI 介入环节说明**：
- **演示环境（当前应用）**：在用户发送消息后，应用内 JavaScript 定时器会在 0.9s ~ 1.5s 的随机延迟后拦截请求。系统将比对用户输入与 `quickPresets` / `demoReplies` 字典，若命中预设场景则输出排版精良的 AI 演示回答；若未命中，则 AI 介入反馈统一的提示文案，告知用户当前处于离线演示模式。
- **生产环境（真实接入逻辑）**：用户提交文本内容 -> 前端封装为 Message Array（含角色上下文） -> 发起 HTTP/Fetch 请求至后端网关 -> 后端携带 API Key 请求 DeepSeek 大模型 -> AI 模型接收提示词并生成推理结果 -> 以后端流式（Stream）响应返回 -> 前端监听到数据流并在界面上逐字动态渲染。

## 4. 技术栈清单
本项目实现了零外部框架依赖，完全采用 Web 标准技术构建，保证了极致的轻量化与加载速度：

*   **核心结构**：**HTML5** (语义化文档结构、SVG 字符替代图标)
*   **视觉与样式**：**CSS3**
    *   全局原生 CSS 变量 (Custom Properties) 管理主题色
    *   Flexbox 与 CSS Grid 现代响应式布局
    *   CSS Animations (`@keyframes`) 实现呼吸灯、光球悬浮、打字机加载动画
    *   `backdrop-filter` 磨砂玻璃物理效果
    *   媒体查询 (`@media`) 实现移动端自适应折叠侧边栏
*   **交互逻辑**：**Vanilla JavaScript** (原生 JS)
    *   DOM 动态元素创建与销毁、事件监听与拦截
    *   纯原生正则表达式 (RegEx) 驱动的简易 Markdown 解析引擎 (支持 \`\`\`代码、加粗、列表、段落渲染)
    *   `setTimeout` 异步模拟与防抖机制
